# 版本历史

这份文档按本地正式 tag 记录 CHun 的演进轨迹。

说明：

- 日期使用 tag 对应 commit 的提交时间
- 仅记录正式版本 tag
- `backup-*` 这类备份 tag 不纳入正文

## v0.0.0 - 2026-04-07

主题：第一版脚本化 pwntools 工具

- 项目起点是一个脚本化的 pwntools 封装
- 当时主要包含 `MyTool` 与 `BuildFmtTool` 两个类
- 这一版更像能力原型，而不是稳定框架

意义：

- CHun 的出发点来自真实手写 exp 需求，而不是先设计大而全框架

## v0.1.0 - 2026-04-07

主题：完成初步框架化

- 从单点脚本工具向框架结构推进
- 开始形成后续可持续扩展的目录与分层基础

意义：

- 这是从“能用”走向“可演进”的第一步

## v0.1.1 - 2026-04-08

主题：补齐首轮文档

- 完成第一批文档编写
- 开始把能力沉淀为可以回看的说明材料

意义：

- 从这一步开始，项目不仅有代码，也开始有可维护的知识面

## v0.1.2 - 2026-04-08

主题：develop 阶段收口

- 合并开发分支上的阶段成果
- 作为 `0.1.x` 收尾版本存在

意义：

- 标记早期框架化阶段的一个稳定截面

## v0.2.0 - 2026-04-17

主题：落地本地 SQLite libc catalog

- 实现本地 SQLite libc catalog
- 建好离线数据构建链路
- 为后续 libc 检索、offset 查询和自动推导打下基础

意义：

- 这是 CHun 从“工具脚本”转向“知识驱动 exploit 框架”的关键一步

## v0.2.1 - 2026-04-17

主题：优化 infer 交互并补齐脚本态 leak 语法糖

- 优化 `search_libc` 交互体验
- 增加脚本态 `recv_leak` 语法糖

意义：

- 把 libc 检索能力从底层数据层真正接回到手写 exp 工作流

## v0.2.2 - 2026-04-17

主题：落地 fmt 插件骨架

- 建立格式化字符串插件骨架
- 加入 offset 探测
- 加入写入编排链路

意义：

- fmt 从零散逻辑变成独立子系统的开端

## v1.0.0 - 2026-04-17

主题：合入 libc catalog、infer 与 fmt 基础能力

- 合并前面几个关键方向的阶段成果
- 本地 libc 检索、推导链路与 fmt 基础能力进入同一主线

意义：

- 这是 CHun 第一阶段可称为“成体系框架”的版本

## v1.1.0 - 2026-04-17

主题：收口 session 状态来源

- 将 `resolve` / `infer` 的状态来源统一收口到 `session`
- 移除旧的 `bind_defaults`、`as_session` 入口

意义：

- 统一 runtime 状态归属，为后面的 registry / replay / workflow 铺路

## v1.1.1 - 2026-04-17

主题：script-session 修正版本

- 合并 `script-session` 相关修复
- 稳定 `v1.1.0` 的 session 收口结果

意义：

- 这是一次围绕主线结构调整后的跟进稳定版本

## v1.1.2 - 2026-04-19

主题：修补 script 中的 fmt 语法糖问题

- 修复 script 中残留的 fmt 语法糖问题
- 为 `find_offset` 增加 `loginfo` 字段
- 默认关闭冗余日志

意义：

- 属于典型的 `Z` 版本：不改大方向，集中打磨使用体验

## v1.2.0 - 2026-04-20

主题：fmt 插件体系成型

- fmt 拥有独立 API 文档
- fmt 子系统从“已有能力”进入“可明确对外描述的模块”

意义：

- 这版可以视为 fmt 方向阶段性竣工

## v1.2.1 - 2026-04-20

主题：重构 fmt 写入算法内核

- 重构 fmt 写入算法内核
- 接入 pwntools backend

意义：

- fmt 从自定义实现向更稳的 backend 复用迈出关键一步

## v1.2.2 - 2026-04-22

主题：补齐 writes facade 与语法糖

- 新增 `writes` facade
- 继续补全手写 exp 侧语法糖

意义：

- 在大功能成型后，继续把高频使用路径做顺手

## v1.3.0 - 2026-04-22

主题：workflow 落地

意义：

- CHun 从单点利用辅助工具进一步走向 exploit 过程建模

## v1.3.1 - 2026-04-22

主题：registry 展示增强并接入 workflow 摘要

## v1.4.0 - 2026-04-24

- 继续向“智能化、自动化、可复用”方向推进
